# Introduction Lecture

## Why should I learn JavaScript

1. **Express yourself**: Craft interactive digital art or personalized web experiences that showcase your creativity.

2. **Create anything: From games to apps**, JavaScript lets you build your digital dreams from scratch.

3. **Solve real problems**: Design web solutions that can genuinely improve people's daily lives.

4. **Boost your programming brain**: Coding in multiple languages, including JavaScript, sharpens your overall programming skills.

5. **Never stop growing**: The ever-evolving JavaScript ecosystem ensures continuous learning and personal development.

6. **Build your own startup: Create a prototype** for your next big idea yourself or together with others.

7. **Earn while you learn: Start freelancing with JavaScript skills** even before graduation.

8. **Work flexibly:** JavaScript's ubiquity allows for remote work opportunities worldwide.

9. **Stay in demand:** JavaScript's popularity means a wealth of job opportunities globally.

10. **Dominate the web:** As the language of browsers, JavaScript mastery lets you shape the entire internet user experience.

## Course walkthrough

- pre-requisites and assumptions about students:
  - have studied programming before
  - knows at least java and python before
  - course will not explain basic concepts **unless** they are different or unexpected
- learning goals
  - learn javascript programming
  - understand javascript code
  - skill in assuring the quality of the code by writing and running unit tests
  - learn an programming language that is popular among developers and employers
    - use industry standard tools
    - use industry standard workflows
      - git clone, pull, commit, pull
      - test first
  - learn to write tests and WORKING code
  - experience of reviewing code and giving valuable and meaninfull improvement suggestions (**peer review**).
    - by reviewing other solutions you will get experience in reviewing code from your peers. This is a extremely common practice in open source projects and commercial projects too.
  - experience of verbally presenting and explaining your code. (**submission of video recording**)
    - Working with any kind of development you will most probably have to explain your code to a colleague at some point.

- course materials
  - **no slides about javascript** instead we will **use examples to learn** how to solve programming tasks with javascript
  - javascript code with comments or unit tests (downloadable from github)
  - example solutions for the assignments
    - library
    - mapgame
    - ghost gobbler
- assignments
  - **Assignment 1**
    - basic programming (Shopping basket)
    - unit tests
    - peer review
    - video presentation
  - **Assignment 2**
    - small game for webpage
    - unit tests
    - html, css
    - video walkthrough
    - publish the game on github
